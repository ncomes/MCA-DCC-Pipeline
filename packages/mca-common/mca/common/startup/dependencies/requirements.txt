# What the framework needs inside a DCC.
#
# mca-common owns this list and nothing else keeps a copy. The launcher reads it and
# installs it per DCC version, with that version's own interpreter, into a folder of its
# own - never into the DCC's installation.
#
# Qt is not here to be installed: every DCC ships its own, and a second Qt on sys.path is an
# abort with no traceback. PySide6 and shiboken6 are listed because some tools check for
# them, and the launcher drops them before installing anything.
#
# A package with no build for a given interpreter is skipped by name rather than taking the
# list down with it - which is how Maya 2022's Python 3.7 keeps working without the two AI
# packages.

numpy
PyYAML == 6.0
PySide6
shiboken6
pluggy
anytree >= 2.8.0
psutil >= 5.9.4
yamlordereddictloader
pytz >= 2023.2
beautifulsoup4 >= 4.12.0
requests >= 2.31.0
anthropic >= 0.18.0
openai >= 1.12.0

# PyMEL. Maya has not shipped it since 2026, and a pip install into the user site
# silently shadows whatever a DCC does ship - so it is managed here like anything
# else, installed per Maya version into that version's own folder.
#
# 1.5.0 is the release that added Python 3.11, which is what Maya 2026 runs. It
# carries prebuilt caches for Maya 2022-2025 and none for 2026; without them PyMEL
# rebuilds from Maya's documentation, which Maya 2026 does not install - so the
# import fails twice over, once on the API cache and once on the command cache.
# The launcher provides both after the import check catches it, from the copies
# committed under mca-common/mca/common/startup/dependencies/pymel_cache - see
# dependencies.recover_pymel_cache and that folder's PROVENANCE.md.
#
# 1.5.0 from PyPI also still declares its own `future` dependency, which PyMEL's
# code needs: pymel/core/uitypes.py imports past.builtins at module level. Later
# third-party forks dropped that declaration without dropping the import, so they
# do not install cleanly. Pin the PyPI release and vendor only the caches.
pymel >= 1.5.0

# Voice input.
vosk >= 0.3.45
sounddevice >= 0.5.0
